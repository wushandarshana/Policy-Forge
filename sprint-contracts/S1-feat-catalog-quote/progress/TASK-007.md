## Open issues
- **Red-log granularity.** The TASK-001 to TASK-006 green logs show passes at class level (`Tests run: N, Failures: 0`), and most do not print individual display names. The per-ID pass proof comes from the XML reports of the final `verify` run, not from the logs. The TASK-005 and TASK-006 red logs record the failing IDs in their headers and in the failure output. The TASK-006 red log notes that the NFR-04.2 "unknown quote ID is 404" test passed before the controller existed.
- **`.gitignore` blocks lcov.info.** The rule `frontend/coverage/` ignores the whole directory, so `!frontend/coverage/lcov.info` has no effect. frontend/CLAUDE.md says the file is committed. Change the rule to `frontend/coverage/*` (a substrate edit for a human). I did not touch `.gitignore`.
- **First build is slow and needs network.** The first `./mvnw` run downloads Node (cached in `~/.m2` afterwards) and runs `npm ci`. `npm ci` deletes and reinstalls `frontend/node_modules` on every Maven build. Use `-Dskip.frontend=true` for backend-only loops. `spring-boot:run` also runs the npm build each time.
- **Windows web-server command.** `playwright.config.ts` uses `.\\mvnw.cmd` on Windows. The shell needs `JAVA_HOME` to point at JDK 21 (see `docs/post-mortems/2026-10-28-jdk-path-environment.md`). Port 8080 must be free. Locally, `reuseExistingServer` is on, so a running backend is reused. CI mode (`CI` set) always starts a fresh one.
- **Only Chromium is installed.** `npx playwright install chromium` is a one-time per-machine step. The CI stage (Sprint 5) must run it too.
- **e2e TypeScript is not type-checked.** `tsconfig.json` includes only `src` and `vite.config.ts`, so `npm run build` does not check `e2e/` or `playwright.config.ts`. Playwright compiles them at run time.
- **No Apply click in the e2e test.** The Apply link has no destination yet (TASK-002 note, J13), so the test only asserts it is visible.
- **`npm audit` advisories** on dev tooling remain, as noted in TASK-002. No `npm audit fix` was run.
- **Visual snapshots are not used** in this smoke test.
