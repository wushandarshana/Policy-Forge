- **Datasource default** is embedded in-memory H2 with Spring's unique name (so each test context is isolated). A file-backed H2 is available with `-Dspring-boot.run.profiles=file` (`./data/policyforge`, already covered by `.gitignore` `*.mv.db`).
- **Security design notes for the security reviewer.** CSRF is disabled (stateless Basic, no cookies). `anyRequest().permitAll()` applies only to non-`/api`, non-`/actuator` paths (SPA assets and client routes, `/error`). Only `health` is exposed by Actuator. Synthetic password `password` is BCrypt-encoded at startup. Inbound `X-Correlation-Id` is echoed only if it matches `[A-Za-z0-9._-]{1,64}`, otherwise a UUID is generated. The request-completed log line contains method, path, status and duration only.
- **Extra shared types added for later tasks:** `service.ValidationFailedException` (with `FieldViolation(field, message)`) maps to 400 with `errors[]`, and `service.ResourceNotFoundException` maps to 404 (`/problems/not-found`). TASK-003's `NoActiveRuleSetException` should extend `ResourceNotFoundException` to get 404 for free. `GlobalExceptionHandler` also has a 500 catch-all that logs the exception (stack trace, no request data) and returns a generic body.
- **Test-only probe controller** (`ErrorMappingIT.ProbeController`, path `/api/_probe/**`) is loaded only through `@Import` in that class and is invisible to other contexts. `SecurityBaselineIT` assumes `/`, `/index.html`, `/assets/app.js` are not 401/403 (they are 404 until TASK-007 packages the SPA).
