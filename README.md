# PolicyForge

Policy Issuance & Lifecycle Management Platform for Horizon Insurance (Capstone BC-AINE-004).
Quote → application/KYC → underwriting → issuance → endorsement → renewal/lapse → cancellation
across three products: Term Life, Motor and Household.

> **AI-native build.** All production code, tests and migrations in this repository are generated by
> Claude Code agents. Humans author only specs, CLAUDE.md files, agent/skill/hook/command definitions
> and other substrate. See [`CLAUDE.md`](CLAUDE.md) and [`AGENTS.md`](AGENTS.md).
