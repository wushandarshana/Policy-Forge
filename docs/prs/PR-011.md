## Scope
- **Two pipelines, same gates (NFR-09.1).** Both run for pushes to `dev` and `main` and for pull or merge requests
  into them:
  - `.github/workflows/ci.yml`, which runs on `origin`;
  - `.gitlab-ci.yml`, which meets the capstone's GitLab CI requirement.
- **Jobs:**
  - `build`: `./mvnw verify` with the SPA, ArchUnit and JaCoCo gates.
  - `frontend-unit`: Vitest with coverage, plus the build.
  - `e2e`: Playwright in the pinned Playwright image, against the packaged JAR.
  - `quality-gates`: AC audit, evidence redaction, hook tests, LF check, CI script tests, AC-08.5 oracle fixture,
    actionlint and CI schemas.
  - `claude-review`: required.
  - `claude-review-comment`.
  - `ci-gate`: the aggregator to require.
- **Supply chain (NFR-09.2):**
  - Every action is pinned to a commit SHA, and every image to a tag plus digest.
  - Downloaded tools are checked against SHA-256 checksums.
  - The Claude Code CLI 2.1.311 installs from a lockfile (`npm ci`), and the Python CI packages from a hashed
    requirements file (`pip install --require-hashes`).
  - `@playwright/test` is pinned exactly, and `.mcp.json` is pinned to `@playwright/mcp@0.0.84`.
- **Least privilege and secrets (NFR-09.3, NFR-09.7):**
  - Permissions default to `contents: read`.
  - There is no `pull_request_target`, and `persist-credentials` is false.
  - No event expression appears in a `run:` script.
  - `ANTHROPIC_API_KEY` lives only in the protected GitHub Environment `claude-review` (the owner approves each run),
    or in a GitLab variable scoped to the protected environment of the same name.
- **Sandboxed Claude review (NFR-09.4, NFR-09.7):**
  - **What it reads:** two passes, using the `security-reviewer` and `test-engineer` agent files verbatim. The CLI has
    `Read`, `Grep` and `Glob` only, with no shell. Reads are limited to the checkout (`/proc`, system roots, `.git` and
    home credentials are denied), and the diff and log are given as files.
  - **What it can't touch:** an allowlisted environment, so no platform token reaches it. The run fails closed if any
    file changes.
  - **When it fails:** any BLOCKER fails the job, and so does a missing key, a wrong CLI version, a CLI error or invalid
    output.
  - **How the result is posted:** a separate job that holds no key, runs base-branch code, edits only its own bot
    comment and accepts `https` only.
- **Visual baselines (NFR-09.5):** an `expectVisual` helper. On a platform with no baselines, it skips only the visual
  assertion and records it. `-linux` baselines come from a CI job triggered by a PR label.
- **Sprint 4 follow-ups:**
  - NFR-08.1: only `EndorsementService` may call `repriceOffer`. Enforced by ArchUnit, with a negative fixture.
  - AC-07.7: a test racing a re-price against a payment.
  - AC-08.5: a cross-check against 1,000 cases generated from `premium_check.py`.
  - `frontend/coverage/lcov.info` is no longer tracked.
  - `mvnw` is now executable.
  - `.github/CODEOWNERS` is added.
- **Specs first:** `4730168` (NFR-08.1, NFR-09.1–09.6, and SG-3/5/6/7 accepted), `be6b9f3` (NFR-09.7) and `47857df`
  (the CODEOWNERS wording and the accepted residual).
