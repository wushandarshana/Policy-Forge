## Why
A read-only audit compared the repository with every graded item in the capstone brief. Nearly every item is met. The
gaps were mostly documentation: a placeholder README quick start, a TDD worked example that cited a commit that doesn't
exist, a stale coverage artefact, no recorded Agent SDK run, and PR records not mapped to GitHub PRs. The Sprint 5
security re-review's minor findings were also open.

## Changes
- **Docs (`49b3b45`):**
  - README quick start, a seed-data table, the sign-in users, a demo walkthrough and a **rubric map** that points to
    each graded item.
  - `docs/tdd.md`: the worked example now uses the real commits (`cd638af` → `831edd4`, refactor `53a2944`), and a
    table lists the red → green commit pairs of every sprint.
  - `docs/prs/README.md`: an index mapping PR-001..PR-012 to GitHub #1–#8 and to their merge commits.
  - The fix-loop traces now each name the PR they landed in.
  - `plugin.json` is now version 1.0.0 and lists all 14 CLAUDE.md files. AGENTS.md adds the hooks CLAUDE.md. The root
    CLAUDE.md now shows the `test(red):` and `feat(green):` commit forms used in the history.
- **Coverage (`f3963e9`):** `coverage/backend/jacoco.xml` is refreshed from the v1.0.0 QA build: 94.0% of
  instructions, 93.5% of lines and 83.9% of branches.
- **Live Agent SDK audit (`96fa2e2`):** the first real run of `scripts/ac_audit.py` through the Claude Agent SDK
  (`specs/reviews/ac-audit-20261105-1439.md`), with a note on how to read it and the follow-ups.
- **CI security minors (TDD: `1ddebcf` red → `0648760` green → `b7aee16` ci → `2e32d26` docs; [trace](../fix-loops/2026-11-05-ci-minors.md)):**
  - The runner fails closed on any symlink that resolves outside the checkout or the worktree.
  - The tree check now also hashes `.git/config`, `.git/info/attributes` and `.git/hooks/`. The CLI files and the
    review inputs are hashed and checked again before each pass.
  - `git` and `ac_audit.py` now run without `ANTHROPIC_API_KEY`.
  - The worktree is created at the PR's head commit (`PF_REVIEW_HEAD_SHA`, validated), not at the merge commit.
  - Results: 210 script tests pass, quality gates 8/8, AC audit 93/93.

## Not changed
