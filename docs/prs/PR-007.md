## Changes
- **`/pr`** pushes the feature branch and opens a PR into `dev` with `gh pr create`, using this record as the body.
  Merges are "Create a merge commit" only: no squash, no rebase, no `--admin`.
- **`/release`** opens a PR from `dev` into `main`. The tag is created only on the merged remote commit and verified
  with `git merge-base --is-ancestor <tag> origin/main`.
- Root **`CLAUDE.md`** rule 3 documents the GitHub PR requirement and the merge-commit-only policy.
- Knowledge deposit **KD-013**: the v0.1.0 push was rejected, and the tag briefly pointed at a commit that wasn't on
  remote `main`.

Commands and docs only. No application or hook code changed. This is the first PR opened through `gh`.
